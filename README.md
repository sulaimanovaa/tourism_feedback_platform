# 🧭 Tourism Review & Recommendation Web System

This project is a web-based review and recommendation system for tourism services, developed as part of my graduation thesis.

## Features
The system allows users to:

- Explore and review tourism-related services (e.g., tours, accommodations, entertainment);
- Leave detailed feedback with ratings, comments, and photos;
- Filter and sort reviews (e.g., with photos, positive, negative, by date);
- Like reviews, follow other users, and save favorite services;
- Register and securely verify their account via email;
- Restore forgotten passwords via email token links.

## Getting Started
```bash
# Clone this repository
$ git clone https://github.com/sulaimanovaa/tourism_feedback_platform.git

# Go into the repository
$ cd tourism_feedback_platform

# Install dependencies
$ npm install

# Run the app
$ npm run start:dev
```
